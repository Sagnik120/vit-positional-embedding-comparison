# docs/

Chronological process log for this project, kept in markdown so the whole
workflow is auditable end to end.

| File | Contents |
|---|---|
| `01_task_definition.md` | The assignment as given, dataset/model-size decisions and why |
| `02_positional_embedding_choice.md` | Why RoPE, alternatives considered and rejected |
| `03_environment_setup.md` | venv creation, dependency install, MPS notes for MacBook |
| `04_diagnostics_log.md` | Output/results of `scripts/run_diagnostics.py` runs |
| `05_training_log.md` | Training run notes: hyperparameters used, wall-clock time, any issues hit and how they were resolved |
| `06_results_log.md` | Final numbers, where each plot/table lives, links back to `report/` |
